# Changelog

All notable user-visible changes to the Homarr TOS application package.

## 2.13.0-1 — 2026-11-14

### Added
- First release. Homarr (`moechz/homarr:v2.13.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8149 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/homarrdocker/`.
